# BuildKiwi

**Build, showcase, and discover projects.**

BuildKiwi is a full-stack project publishing platform for developers. It brings project pages, public profiles, and reusable generated SVG cover patterns together in one place.

- **Live site:** https://buildkiwi.space
- **Repository:** Add your GitHub repository URL here
- **Status:** Under active development


## Security

Please do not report exploitable security issues in public issues. Contact the repository maintainer privately through a verified contact method listed on the project's GitHub profile.
